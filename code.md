# Main Technologies Used in CodeBid

Here is a list of the primary technologies and packages powering the CodeBid application:

- **Flutter**: The core UI toolkit for building cross-platform applications from a single codebase.
- **Dart**: The programming language underlying the Flutter framework.
- **GetX**: Utilized for robust state management, rapid dependency injection, and simplified route navigation without context.
- **Firebase**: 
  - **Firebase Auth**: For secure user authentication (Email/Password).
  - **Firebase Realtime Database & Cloud Firestore**: Used as the NoSQL database solutions to store and sync application data (such as users, tasks, bids) in real-time.
  - **Firebase Storage**: Used for storing user-generated files and media.
- **Google Sign-In**: Enables seamless authentication using Google accounts.
- **Image Picker**: Facilitates selecting images from the device gallery or capturing new ones via the camera.
- **HTTP**: Used to handle network and API requests.
